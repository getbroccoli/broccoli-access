# App logos

Logos of the built-in catalog apps, named by catalog key and bundled with the web app, so the
browser never asks a third party for them. Each file is the icon from
[Simple Icons](https://simpleicons.org) 16.38.1, released under
[CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md), with its brand
colour added as `fill`. The brands remain their owners' trademarks; Simple Icons'
[disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md) applies.

- `calendly.svg`: Calendly, source https://calendly.com/newsroom
- `claude.svg`: Claude, source https://claude.ai
- `figma.svg`: Figma, source https://www.figma.com/using-the-figma-brand/
- `grammarly.svg`: Grammarly, source https://www.grammarly.com/media-assets
- `loom.svg`: Loom, source https://www.loom.com/press
- `miro.svg`: Miro, source https://miro.com
- `notion.svg`: Notion, source https://www.notion.so

The other catalog apps show their initial: Simple Icons has no icon for them, or only a wordmark
that a small square cannot show (Typeform, Zoom).

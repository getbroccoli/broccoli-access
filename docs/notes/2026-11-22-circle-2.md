# Circle 2 decisions (2026-11-22)

Scope is in [circle 2](../circle2.md). This note keeps the reasons.

## Why

- **App sessions, not robots.** On the plans small companies buy, most paid apps have no API for members and keep SCIM for enterprise plans. Linear has an API on every plan. Slack has no public API that can deactivate members below Enterprise Grid, and no SCIM below Business+. But Slack's own admin pages call web methods that open-source projects already use from servers with an admin's session. Circle 2 makes the same calls with the owner's handed-over session, so it needs no browser robot.
- **The owner's own session, handed over by the extension.**
  - No password or MFA secret is ever stored.
  - Google blocks sign-in in a browser that automation launched, unless the automation hides itself, which broccoli-access never does. The owner's everyday Chrome is a normal browser, so that block never applies.
  - The extension sends only the app's own cookies and the local storage keys its manifest names: nothing from Google or any other site.
- **Server, then by hand.**
  - The server works with nobody present.
  - The owner can always make the change by hand, and broccoli-access records it.
  - Running a change in the owner's Chrome stays in the contract for a later app whose pages need a robot. Circle 2 does not build it, which also keeps the extension free of the debugger permission.
- **No tasks in circle 2.** A failed change shows why on the account, with Try again and "I did it by hand", and the "Suspended with access" count keeps showing a leaver who still has access. An Activity page lists every change. A Tasks page earns its place when tasks go to other people, in circle 3.
- **The extension holds no app steps.** What to hand over, cookies for some domains and a few local storage keys, comes from the connector's manifest, so a new app needs no extension release.
- **Connectors in their own repository and container.**
  - Apps change their pages without notice, so connectors need their own release cycle: a fix ships without a core release.
  - The core stays the same for every app.
- **Only Slack and Linear.** One app through its public API and one through the owner's app session, end to end, so later apps reuse what circle 2 builds.

## Open checks

- How long a Slack session lasts when only the server uses it, and whether the daily scan keeps it alive.
- Whether Slack accepts its own web methods from a server with a handed-over session.
- Whether Slack's free plan lets an admin deactivate a member: an old reference marks `users.admin.setInactive` as paid only.
